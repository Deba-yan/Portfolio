## 🚀 About This Project

This portfolio is more than just a static page; it's a curated space that reflects my developer identity. It is designed to provide a clear, modern, and responsive overview of my skills, projects, and achievements for potential collaborators and employers.

**Key sections include:**

*   **🏠 Hero Section:** A brief introduction and a fun, interactive JavaScript object that summarizes my developer profile.
*   **👨‍💻 About Me:** A snapshot of my background, interests, and current focus as a B.Tech CSE student.
*   **🛠️ Tech Stack:** A visual list of the programming languages, frameworks, and tools I work with.
*   **💼 Selected Work:** A gallery of my key projects with links to their live demos or repositories.
*   **🏆 Journey:** A summary of my notable achievements, including LeetCode ratings, hackathon wins, and academic performance.
*   **🔗 Coding Profiles:** Direct links to my professional profiles on GitHub, LeetCode, and LinkedIn.
*   **📬 Contact:** A clear call-to-action with my location for networking opportunities.

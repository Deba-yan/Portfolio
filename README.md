# Developer Portfolio

A modern responsive portfolio built with HTML, CSS and JavaScript.

## Before publishing

Replace these placeholders in `index.html`:
- `Your Name`
- `https://github.com/`
- `https://www.linkedin.com/`
- `https://leetcode.com/`
- `your.email@example.com`

For each project, replace the GitHub links with the actual repository URL.

To add your resume, place a file named `resume.pdf` in the root folder.

## Run locally

Open `index.html` directly in a browser, or run a local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
